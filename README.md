# 不動産査定ツール

## 概要

国土交通省が公開している不動産取引価格情報を利用し、
入力した物件に近い過去の取引事例を検索する
不動産取引価格査定ツールです。

不動産業務の経験を活かし、実際の業務に関連する
アプリケーションをJavaで開発しました。

## 開発背景

現在、不動産会社で働いており、自分が実際に扱っている「不動産」をテーマにした
アプリケーションを作ってみたいと考えました。

実際に売却・購入の明確な意向がない中で、
目安の不動産売買価格を知りたいという声が多かったため、
作成することに至りました。

そこで、国土交通省が公開している不動産取引価格情報を利用し、
入力した物件と条件の近い過去の取引事例を
検索できるツールを開発しました。

なお、実際の査定では、駅距離や階数などの細かな要因によって
査定金額は変動しますが、簡易査定では、
お部屋の面積と建物の築年数が主な要因となるため、
現時点ではこの2項目を利用したツールとしています。

## 主な機能

### 1. 不動産取引データの読み込み

国土交通省が公開している不動産取引価格データ
（港区赤坂限定）をCSVファイルから読み込みます。

### 2. 物件情報の入力

査定したい物件について、

- 専有面積
- 築年数

を入力します。

### 3. 類似物件の検索

入力された物件と過去の取引事例について、
面積と築年数の差を計算し、類似度を算出します。

現在は、124件の取引事例から類似度の高い5件を選定し、
参考物件として取引価格、サイズ、築年、類似度を表示します。

### 4. エラー処理

面積や築年数に数字以外が入力された場合、
エラーメッセージを表示して再入力を促します。

## 査定ロジック

現在は、

- 面積の差
- 築年数の差

を利用して類似度を計算しています。

条件が完全一致の場合を類似度：100とし、
入力物件との条件の差が小さいほど、
類似度が100に近づく仕組みです。

具体的には、

- 築年数：1年の差につき1ポイント減点
- 面積：1㎡の差につき3ポイント減点

として類似度を算出しています。

なお、この減点幅については現時点では
実データを統計的に分析して決定したものではなく、
面積の方が価格への影響が大きいと考え、
築年数よりも重みを持たせる形で設定しています。

## 開発で意識したこと

### ① 査定精度向上

当初は、類似物件を選定し、
類似度の高い物件の平均値を査定価格として提示していましたが、
金額が想定より大幅にズレてしまう結果が出たため、
類似度による加重平均を用いて算出する方法に変更しました。

また、加重平均で算出するため、
当初は類似度：0を完全一致としていましたが、
加重平均で扱いやすくするため、
完全一致を類似度：100とする方式に変更しました。

### ② 類似度の計算

完全一致の場合を類似度：0としていた方式から、
類似度：100とする方式に変更する際、
単純に割合で計算すると、似ている物件が少ない場合に
類似度が偏ってしまうという欠点がありました。

そこで、類似度を求める際、
あえて「似ていない部分」を100から引く減点法を採用しました。

この方法により、表示結果の下限を設けず、
似ていない物件についてはより低い類似度として
表示できるようにしました。

### ③ 推定価格の表示

不動産知識がない一般の方が使うことを想定し、
より直感的に価格が分かるよう、
「○億○○万円」という形式で結果を表示するようにしています。

システム内部では算出した金額を保持し、
表示時には細かな金額を切り捨て、
「123,456,789円」→「約1億2300万円」のように
分かりやすい単位で表示しています。

「000,000,000円」のように細かな金額まで表示するよりも、
価格の規模を直感的に把握しやすいと考えたためです。

### ④ 実際の業務に関連するテーマを選択

単純な学習用アプリケーションではなく、
自分の不動産業務の経験を活かせるテーマを選びました。

### ⑤ 実際の公開データを利用

架空のデータではなく、
国土交通省が公開している実際の取引価格データを
CSVとして読み込み、処理するようにしました。

## 苦労したこと

### CSVファイルの読み込み

CSVファイルをJavaから読み込む際に、
ファイルパスや文字コードの違いによるエラーが発生しました。

実際にエラーの原因を確認しながら、
CSVを正しく読み込めるように修正しました。

### データの扱い

CSVには多くの項目が含まれているため、
査定に必要なデータを確認し、
必要な項目をJavaで扱える形に整理しました。

## 今後の改善

現在は面積と築年数を中心に類似物件を検索しています。

また、現在の自身の仕事での主要取引エリアの一つが港区赤坂であるため、
赤坂限定での取引事例を用いています。

今後は、

- 港区赤坂以外のエリアを含め、エリアごとでの検索
- 駅からの距離
- 所在階
- 間取り
- 方角
- 取引時期

などの情報も利用し、
より実際の査定に近い仕組みに改善していきたいと考えています。

また、現在設定している類似度の減点幅についても、
実際の取引データを分析し、
より適切な値に改善していきたいと考えています。

コードの整理やクラス・メソッドの役割分担についても
改善していく予定です。
